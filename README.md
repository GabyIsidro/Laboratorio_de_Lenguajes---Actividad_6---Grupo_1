Actividad N°6: POO en Python (Herencia) - Sistema de Estadísticas de Fútbol

Este proyecto consiste en el desarrollo de un sistema computacional orientado a objetos diseñado para que el Director Técnico de un equipo de fútbol pueda controlar las estadísticas de sus jugadores. El sistema ha sido desarrollado utilizando Python y aplica conceptos avanzados del paradigma orientado a objetos (POO).

 Descripción del Problema

El sistema permite administrar los datos de los jugadores de un equipo, incluyendo:

    Número de camiseta.

    Apellido.

    Posición (arquero, defensor, central o delantero).

    Minutos jugados.

    Goles marcados (exclusivo para jugadores de campo, exceptuando al arquero).

 Conceptos de POO Aplicados

El desarrollo se basa en los pilares de la programación orientada a objetos explicados en la teoría de la asignatura:

    Herencia: Se utiliza una clase base Jugador que contiene los atributos comunes, de la cual derivan clases específicas como Arquero y JugadorCampo.

    Encapsulación: Todos los atributos de las clases son privados (utilizando el prefijo __) para proteger la integridad de los datos, accediendo a ellos mediante métodos get y set.

    Polimorfismo: Se implementan métodos como mostrar_datos() que funcionan de manera distinta según el tipo de jugador, permitiendo mostrar u ocultar la estadística de goles según corresponda.
